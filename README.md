# ADOLAT

GitHub Pages uchun tayyor statik huquqiy yordamchi.

## Ishga tushirish

Papka ichidagi barcha fayllarni GitHub repository ildiziga yuklang:

- `index.html`
- `style.css`
- `app.js`

GitHub repository ichida **Settings → Pages → Deploy from a branch → main / root** ni tanlang.

Sayt hech qanday backend talab qilmaydi. Arizalar va kuzatuv ma’lumotlari foydalanuvchining brauzerida saqlanadi.
